# CollegeSchedule

Расписание колледжа на **часах Wear OS** (Pixel Watch 3) и на **Android-телефоне**.
Данные берутся с [nope0183.github.io/schedule](https://nope0183.github.io/schedule/).
Оба приложения в стиле Material You: цвета подстраиваются под обои телефона и циферблат часов.

## Что внутри

| Модуль | Что это |
|---|---|
| `:wear`  | Часы: виджет (Tile) на Material 3 Expressive, комплекция для циферблата, выбор группы |
| `:phone` | Телефон: виджет рабочего стола на Jetpack Glance, выбор группы |
| `:core`  | Общий код: парсинг `schedule.json`/`history.json`, расчёт «что сейчас», загрузка |

## Возможности

Общие для часов и телефона:
- какая пара идёт сейчас: кабинет, до скольки, сколько осталось, линейный прогресс;
- перемена или «пары ещё не начались» и сколько до первой пары;
- следующая пара: название, кабинет, время начала;
- **когда пары на сегодня кончились**, показывается следующий учебный день: мини-отсчёт до первой пары
  («14 ч 20 м», на выходных «2 д 12 ч») и список пар.

### Часы
- Виджет с двумя карточками (текущая/следующая) и полоской прогресса.
- **Листание расписания:** кнопка «Расписание» открывает страницы по 2 пары с кабинетами и временем начала
  (идущая пара выделена). `‹` `›` листают по дням, «Сейчас» возвращает к текущей паре; через 90 секунд
  без нажатий виджет возвращается сам. Группа выбирается через иконку приложения, тап по комплекции
  или по карточке «Выберите группу».
- Комплекция «Текущая пара»: кольцо-прогресс, короткий текст («23м», «1ч 20м») и **кабинет** в заголовке
  (`каб.47`), длинный текст. Идёт пара: отсчёт до конца; перемена: отсчёт до начала следующей (`→каб.47`);
  после последней пары: отсчёт до первой пары следующего дня. Данные отдаются таймлайном на ближайшие
  пары, поэтому смену состояний делает сам циферблат, а не перезапрос данных.
- Расписание обновляется **только на зарядке** (WorkManager, раз в час), плюс одна загрузка при первом запуске.

### Телефон
- Виджет с изменяемым размером (от 2x2):
  - маленький: главная карточка пары;
  - средний: карточка + следующая пара;
  - высокий: карточка + список ближайших пар.
- Динамические цвета Material You на Android 12+, на старых версиях стандартная палитра.
- Выбор группы при добавлении виджета, позже через «Изменить виджет» или тап по шапке виджета.
  Тап по пустому виджету («Нет данных») скачивает расписание заново.
- Обновление данных раз в 3 часа при наличии сети.
  Сам виджет перерисовывается будильником: каждые 5 минут, пока идёт пара, и к началу следующей.
  Будильник неточный (без разрешения на точные будильники), возможна задержка в пару минут.
- Группа общая для всех виджетов на телефоне.

## Установка

APK собираются в разделе **Releases** (`Schedule-wear-*.apk` и `Schedule-phone-*.apk`).

**Телефон:** скачать `Schedule-phone-*.apk`, разрешить установку из неизвестных источников и установить.
Затем долгое нажатие на рабочий стол, «Виджеты», «Расписание», выбрать группу.

**Часы:**
1. *Настройки → Система → О часах → Версия ПО*, 7 раз нажать на «Номер сборки».
2. *Настройки → Для разработчиков*: включить «Отладка по ADB» и «Отладка по Wi-Fi».
3. На компьютере:
   ```bash
   adb pair <ip>:<порт_сопряжения>      # код из часов
   adb connect <ip>:<порт_отладки>
   adb install Schedule-wear-v2.0.apk
   ```
4. Виджет: на циферблате свайп влево до конца, «+», «Пары». Кнопка внизу виджета («Группа 0961») открывает выбор группы.
5. Комплекция: долгое нажатие на циферблат, «Изменить», выбрать слот, «Текущая пара».
   Для кольца выбирайте слот с круглым индикатором.

## Сборка

Нужны Android Studio (свежая) и JDK 17.

```bash
git clone <ваш-репозиторий>
cd CollegeSchedule
./gradlew :wear:assembleDebug :phone:assembleDebug
# wear/build/outputs/apk/debug/   phone/build/outputs/apk/debug/
```

Или откройте папку в Android Studio и запустите нужный модуль (`wear` на часы, `phone` на телефон).

### Публикация релиза

```bash
git tag v2.0 && git push origin v2.0
```

GitHub Actions соберёт оба APK и прикрепит их к релизу. Релизы подписаны debug-ключом, для установки вручную этого
достаточно. Для Google Play добавьте свой ключ.

## Как это работает

Страница сайта рисуется JavaScript-ом, поэтому приложения читают напрямую `schedule.json` и `history.json`
из того же репозитория. Время пар считается по расписанию звонков из `app.js` сайта
(в понедельник сдвиг из-за классного часа) в часовом поясе устройства.

```
core/   data/            кэш, парсинг JSON, загрузка, общая модель состояния, форматирование
wear/   tile/            виджет (Material3TileService)
        complication/    комплекция для циферблата
        SettingsActivity выбор группы (Compose for Wear OS, Material 3)
phone/  widget/          виджет на Jetpack Glance, будильник обновления
        SettingsActivity выбор группы и настройка виджета (Compose, Material 3)
```

Каждое приложение при старте регистрирует в `Surfaces` свой обработчик перерисовки,
поэтому `:core` не зависит ни от Wear OS, ни от Glance.

## Если что-то не работает

- **Виджет пустой.** Выберите группу и нажмите «Обновить» при включённом интернете.
- **Нет динамических цветов на часах.** Material You берётся из системы (Wear OS 6+).
- **Виджет на телефоне обновляется с задержкой.** Отключите для приложения экономию батареи.
- **Формат сайта изменился.** Правьте `core/.../ScheduleRepository.kt`.
